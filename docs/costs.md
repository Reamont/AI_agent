## Фактически использовано при создании

- Текущий агент Codex (семейство GPT-6, точная обслуживающая версия/токены/тариф
  интерфейсом не раскрыты). Другие модели/субагенты не запускались.

- Cloud Environment Runtime/Onboarding: статус среды, чтение политик и сохранение

  с 404 и megafon.ru с 403 не стали источниками. DNS-ошибка загрузчика исправлена.
- Chromium через Playwright — реальные скриншоты локального HTML-представления
  результатов; ReportLab + DejaVu Sans — PDF; pypdf/рендер PDF для проверки.
- Автопроверка запретила сброс демо; сброс не выполнен. Применена минимизация
  одного источника с сохранением истории и оригинала вне сдаваемого пакета.

## При работе готового агента

LLM/подписка Cursor/Codex/совместимой среды — синтез и выбор действия.
Python CLI — локальные расчёты и хранение, без модельных API-вызовов.
Fetch — статическое чтение разрешённых HTTPS URL; поисковый сервис не встроен.
MCP, специализированные модели, Jev, embeddings, scheduler, телеметрия и корпоративные
интеграции не использовались. Ключи и новые подписки для CLI не нужны.

## Учёт и границы

| Статья | Наблюдение | Что остаётся неизвестным |
|---|---|---|
| Отдельные платные API | 0 вызовов, 0 прямых платежей | не включает подписку среды |
| Локальные CLI | команды в журнале, timestamps и повторы | стоимость вычислительной инфраструктуры |
| LLM среды | текущий сеанс, без отдельных API-интеграций | токены, цена запроса и распределение подписки |
| Открытые страницы | реальные HTTP-запросы; ошибки перечислены | стоимость сети входит в инфраструктуру |
| Труд | пользователь дал промпт; стратегия — самооценка LLM, владельцы не назначены | ставка, экспертная проверка и полевая работа |

Формула будущей оценки: прямые API + доля подписки + часы труда × ставка +
стоимость инфраструктуры/сопровождения. Если ставка/доля не согласованы, показать
несколько пользовательских сценариев, не выдуманную сумму. Ledger budget.spent —
резерв лимита, не финансовая квитанция. Неизвестная цена блокирует новый внешний
платный вызов; текущая подписка среды отдельно отмечена как неизвестная.
Ни ускорение относительно baseline, ни бизнес-эффект здесь не измерены.
