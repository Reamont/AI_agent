## План

1. Минимальная вертикаль на Python 3.12: файлы → источники → утверждения → стратегии → checkpoint.
2. Извлечение форматов, защищённое чтение сайтов, расчёты, зависимости и бюджет.
3. Учебное демо: реальное исполнение инструментов + синтез текущей LLM, второй сценарий.
4. Негативные и интеграционные тесты, перенос в новую папку.
5. PDF, архив, точный реестр недостающих элементов. Внешние публикации не выполнять.

## Допущения

- Это разработка нового проекта по просьбе пользователя, а не продолжение ограниченного onboarding.
- Один ведущий агент среды; отдельные модели, MCP, фоновые процессы не требуются.
- Платные API: лимит 0; тариф текущей LLM/подписки и токены неизвестны.
- Демо учебное; синтетические данные не описывают МегаФон. Решения людей только симулированы.

### Ограничение минимизации источника

Чтобы публичный контакт автора не попал в пакет, полный снимок Python statistics
сохранён только в исключённом private/. В текущем состоянии — необходимый фрагмент,
его хеш, исходный полный response SHA256, URL и оригинальный line:76. Исторические
метаданные не переписаны; полные исторические веб-байты намеренно не входят в перенос.
Контрольные суммы JSON-истории и активные ссылки/цитаты сохранены.
