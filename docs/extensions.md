# Дополнительные возможности: решение о пользе

| № | Возможность | Статус | Ценность / затраты | Свидетельство / границы |
|---|---|---|---|---|
| 1 | Интервью | частично | гайд без наводящих вопросов; реальный полевой труд не выполнен | knowledge/interview-guide.md; нет реальных интервью и доказательства спроса |
| 2 | Изображения/аудио/видео/OCR | не реализовано | не требуется основной задаче; не добавляем стоимость API | PDF текстовый слой не называется OCR; screenshots только для отчёта |
| 3 | UX | частично | метод наблюдения и тест пересказа | второй сценарий планирует проверку; реальный UX-тест не проведён |
| 4 | Анализ данных | реализовано в пределах CSV retention | воспроизводимость и ошибки метрик за малую стоимость | тест weighted .725, плохой CSV, demo analysis; нет универсальной аналитической платформы |
| 5 | Поддержка решений | реализовано | сохраняет обязательства, владельцев, сроки и основания | D-01/D-02, owner не назначен; фона нет |
| 6 | Пересмотр | реализовано | не позволяет устаревшим основаниям незаметно жить | C-WINDOW → D-01/P-PILOT, history, tests |
| 7 | Routing | частично | выбирает тип инструмента по вопросу | AGENTS и две разные задачи; авто переключения моделей нет |
| 8 | Skills/hooks/subagents | не реализовано как исполняемые компоненты | один ведущий агент достаточен, нет конфликтов общих решений | workflow — инструкция, не hook; отдельные агенты не запускались |
| 9 | MCP/CLI | CLI реализован; MCP не реализован | простой терминал без обязательных серверов | unittest и живой fetch; названия MCP не выдаются за интеграцию |
| 10 | База знаний | частично | методика + поиск слов/связей + история | search/linked; смысловой поиск и embeddings не реализованы |
| 11 | Устойчивость | реализовано в локальных границах | атомарная база, CAS, lock, checkpoint, error без выдумок | тесты сбоя до commit и tamper; power-loss/сетевой FS не гарантированы |
| 12 | Переносимость | реализовано и проверяется чистой копией | нет абсолютных путей материалов | evals/verification.json; GUI другой среды не проверен |
| 13 | Baseline | протокол готов, измерение не выполнено | исключает выдуманную экономию | evals/baseline.md; нет независимого чата/аналитика |

Польза выше подтверждена функциональными примерами (находится ошибка, сохраняется
статус), а не измерением бизнес-эффекта или превосходства над аналитиком.
