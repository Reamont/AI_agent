Версия в pyproject.toml — 0.2.0. MANIFEST.json внутри ZIP даёт SHA256 каждого файла.
archive_integrity проверяет ZIP, project_validation — активные состояния;
ни один флаг не означает экспертное качество стратегии или готовность всей сдачи.
История исходных прогонов сохранена. Первое «обновление D30» было доступно до D-01:
это **отложенная интерпретация**. После ревью действительно добавлен новый источник
после resume; текущие выводы — [revision.md](../projects/demo/outputs/revision.md).

GitHub API при попытке прочитать метаданные доступа вернул Forbidden. Native Git
чтение/отправка проверяются отдельно; новых токенов и расширения сети не запрашивали.
Авторизованная отправка в существующий репозиторий не меняет его видимость.
Конфигурация облачной среды не перепубликовывалась и не применялась повторно.

## Последние шаги капитана

1. Открыть настоящий **новый** чат в выбранной среде, дать AGENTS.md и
   prompts/first-message.md. Прочитать resume/impact, получить разрешённые входы для
   следующего действия либо явно использовать учебный материал. Сохранить вход,
   ответ и вызовы как отдельный прогон; текущую трассу новым чатом не называть.
2. Записать полный реальный путь по video-script.md; текущие 40 секунд использовать
   только как помеченный фрагмент технической проверки, не как замену исследования.
3. Разместить ZIP, PDF и полный ролик на Яндекс Диске, проверить реальное открытие
   от имени жюри/без авторизации. Добавить три настоящие ссылки и дату проверки сюда.
4. Финальную отправку в личном кабинете выполняет капитан. Baseline допускается
   оставить «не измерено»; эффективность и экономия до измерения не заявляются.
