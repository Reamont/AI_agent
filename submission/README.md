Версия сдаваемого исходника 0.1.0 в pyproject.toml. Точный состав и SHA256 каждого
файла в MANIFEST.json внутри ZIP; сам архив проверен testzip и независимым чтением
хешей. Точная версия Git-исходника определяется commit ветки main. PDF и архив
фиксируют первоначальное состояние подготовки до отправки исходника на GitHub;
они не подтверждают доступ жюри. Видимость репозитория при отправке не изменяется.
Публикация облачной среды и Git push — разные операции; конфигурация среды при
отправке коммита не меняется.

Для жюри: сначала прочитать README, затем demo/outputs/revision.md — именно там
актуальный итог после новых данных. Старые product/communication/strategy.json
сохранены как версия до пересмотра, а не безусловная текущая рекомендация.
