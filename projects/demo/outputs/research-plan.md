# Вопросы решения и условия остановки

Этот план и синтез составлены текущей LLM среды. Он не заполняется CLI автоматически.

| Вопрос | Что меняет | Гипотеза и метод | Приоритет / затраты | Достаточность / fallback |
|---|---|---|---|---|
| Совпадает ли D30? | Можно ли считать снижение реальным | Проверить определение, зрелость и события | 1, локальный документ/таблица, платных API 0 | Одинаковое окно доказано; иначе аудит и остановка масштабирования |
| Где изменение? | Выбор сегмента и объёма пилота | Взвешенные счётчики по периоду, затем когорты | 2, локальный Python | Чистые строки, корректные знаменатели; иначе исправить данные |
| Мешает ли приглашение? | Нужен ли продуктовый прототип | События пути и наблюдение задачи | 3, труд неизвестен | Наблюдаемая проблема; нет доступа → не утверждать причину |
| Есть ли экономика? | Улучшать, pivot или закрывать | Вклад и стоимость поддержки, сценарная чувствительность | 4, реальные входы отсутствуют | Смета и владелец; нет входов → не обещать окупаемость |
| Понимают ли сообщение? | Допустимое обещание и канал | Тест пересказа без подсказки | После подтверждения задачи; план, не проведён | Не обещать будущее как готовое; тест не доказывает спрос |

Стоп в фактическом демо: обнаружено несопоставимое окно D30. Данных для инвестиционного
решения недостаточно; предлагается аудит. Не требуется бесконечный обзор рынка.
