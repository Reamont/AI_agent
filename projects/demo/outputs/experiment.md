# План проверки

Сохранённая рекомендация до новых данных; не утверждённое решение.

**action:** Успех → согласовать пилот; провал → пересмотреть механизм; недостаточно данных → исправить метод, не масштабировать

**baseline:** Реальный baseline неизвестен; синтетический расчёт не baseline эксперимента

**business_effect:** Минимальный эффект должен покрыть разработку/поддержку; величина пока не согласована

**change:** Упрощённый прототип приглашения

**control:** Текущий прототип пути; затем рандомизация команд при достаточном потоке

**duration:** План: до 2 недель прототипа; D30 измерять только после полного окна, срок пилота после расчёта выборки

**failure:** Барьер не наблюдается либо прототип не улучшает выполнение задачи

**guardrails:** Жалобы, отказ от приглашения, нагрузка поддержки, корректность доступа, отсутствие спама

**hypothesis:** Если ручной первый шаг — барьер, прототип позволит выполнить совместную задачу без подсказки

**id:** EXP-01

**inconclusive:** Не та аудитория, недостаточно наблюдений, незрелая когорта или ошибки событий

**metric:** Завершение первой совместной задачи; для следующего пилота корректный D30

**owner:** не назначен

**sample:** Сначала 5–8 наблюдений как план диагностического теста, не оценка спроса. Для причинного пилота рассчитать выборку после baseline и MDE, без обещания значимости.

**success:** Диагностика выявила понятный исправимый барьер; решение о пилоте после сметы, baseline и MDE

**unit:** Команда; интервью/тест с согласия представителя
