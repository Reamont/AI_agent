# Учебный бриф — не официальный материал МегаФона

Продукт «Контур задач» вымышлен. Запрос руководителя и уточнение — сценарий,
не фактическое интервью с пользователем. Цель: выбрать направление инвестиций
и коммуникации при предполагаемом падении удержания. Решение принимает владелец,
который пока не назначен. Реального срока нет. Лимит платных API: 0 RUB.

**Запрос:** «Удержание падает — надо менять продукт или сообщение?»
**Уточнение в сценарии:** D30 — доля активированных команд, вернувшихся на 30-й день;
выбираем между сохранением, улучшением, новым сегментом и закрытием направления.
**Существенная неизвестность:** сопоставимы ли окна наблюдения? Проверить до инвестиций.

Исходный подробный документ: inputs/brief.docx. Синтетические счётчики:
inputs/cohorts.csv. Плохой набор специально содержит пропуски и ошибку периода.
Внешний сайт — официальная документация Python, только методическое основание,
не исследование рынка. Официальный бриф не предоставлен; megafon.ru при проверке
04.11.2026 вернул через прокси 403. Поисковый инструмент отсутствовал;
полный поиск официального брифа не проведён.

Замена брифа: создать новый проект init с новым конфигом, импортировать разрешённый
официальный документ, пересмотреть вопрос решения; не переименовывать синтетику
в реальные данные и не копировать выводы демо. Для обновления того же проекта
использовать ingest --supersedes и impact.
