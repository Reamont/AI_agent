# Вторая задача: объяснение прав, не удержание

Учебный сценарий. Вопрос: «Как объяснить читателю ценность общего каталога и права?»
Текущая LLM прочитала фактически извлечённый PDF и HTML, зарегистрировала C-ACCESS
с page:1, выбрала проверку понимания вместо когортного анализа.

Гипотеза сообщения: «Ищите книги в общем каталоге; изменения вносит библиотекарь».
Подтверждение возможности — синтетическая памятка, не доказательство понимания.
Следующий шаг: гайд пересказа роли; реальные респонденты только с согласием.
Полная вторая стратегия не строилась. Сохранение и проверка состояния выполнены.
Команда: `python -m strategist -p projects/second resume`.
