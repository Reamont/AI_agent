# Baseline — НЕ ИЗМЕРЕНО

До независимого сравнительного прогона фиксируем протокол и рубрику. Эта сессия не
содержит отдельного обычного чата на равных условиях. Не утверждаем ускорение,
экономию, процент улучшения и превосходство над профессиональным аналитиком.

## Протокол

Baseline: обычный новый чат той же LLM, без AGENTS/workflow/памяти. Одинаковые inputs
demo, доступ к тому же открытому методическому источнику, без закрытых данных,
лимит внешних API 0, 60 минут; модель и тариф зафиксировать. Нельзя давать baseline
готовые outputs/claims/пересмотр. Перед началом дать только неоднозначный запрос
из brief.md и исходные DOCX/CSV/XLSX. Затем одинаковое обновление измерения.

Зафиксировать входы, точные ответы, инструменты/токены при доступности, время,
повторы и вмешательства. Сохранить артефакты baseline отдельно. Оценщику случайно
показать анонимные A/B; 0 = отсутствует/неверно, 1 = частично, 2 = проверяемо.
Неизвестные расходы остаются неизвестными. Если один прогон, n=1 и без обобщения.

## Общая рубрика

1. Источники: существующие URL/хеши и точные локаторы.
2. Разделены факты, гипотезы, прогнозы, область и неопределённость.
3. Четыре стратегически разных варианта, честные статус-кво и закрытие.
4. Сильные возражения, опровергающие данные и чувствительность.
5. Продукт и коммуникация согласованы, обещания доказаны/ограничены.
6. План проверки: контроль, единица, baseline, sample, guardrails, неуспех.
7. Продолжение после паузы и пересмотр по новому окну измерения.
8. Время/прямые расходы/подписка/труд/вмешательства отдельно.

Цена текущего решения: первоначальная разработка, сопровождение схемы, ручной синтез
LLM, проверка прав и качества источников, назначение владельцев и полевая проверка.
Самооценка текущего агента не независимая экспертиза.
